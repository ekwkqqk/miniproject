# 대시보드 기능 정의서

| 항목 | 내용 |
|------|------|
| 문서 버전 | 1.0 |
| 작성일 | 2026-07-21 |
| 대상 시스템 | miniproject (Vue 3 + Spring Boot) |
| 상태 | **확정** (구현 기준) |

---

## 1. 목적

로그인 후 **홈 화면**으로, 현재 사용자 기본 정보와 메뉴 버튼 권한 데모를 표시한다.

---

## 2. 메뉴·경로

| 항목 | 값 |
|------|-----|
| 메뉴명 | 대시보드 |
| 메뉴 URL(시드) | `/` |
| 앱 라우트 | `/dashboard` (`/` → redirect) |
| i18n key | `menu.dashboard` |
| 접근 | 인증 사용자 (시드: 전 Role `canRead`). 라우트 `requiresMenu` 없음 |

---

## 3. 기능 범위

| ID | 기능 | 설명 |
|----|------|------|
| D-01 | 프로필 요약 | 이메일, 이름, Role 목록, 가입일 표시 |
| D-02 | 버튼 권한 데모 | 현재 메뉴 기준 `v-can` 버튼 권한 표시 |

### 제외

- 통계·위젯·업무 알림 집계 (결재 뱃지는 사이드바/폴링으로 별도)

---

## 4. API

| Method | Path | 설명 |
|--------|------|------|
| GET | `/api/users/me` | 현재 사용자 |
| GET | `/api/menus/my` | 사이드바·권한 (레이아웃) |
