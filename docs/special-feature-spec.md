# 특별 사용자 기능 정의서

| 항목 | 내용 |
|------|------|
| 문서 버전 | 1.0 |
| 작성일 | 2026-07-21 |
| 대상 시스템 | miniproject (Vue 3 + Spring Boot) |
| 상태 | **확정** (구현 기준) |

---

## 1. 목적

**Role 기반 메뉴 접근**을 검증하는 샘플 영역이다. `SPECIAL_USER`(및 시스템관리자)만 메뉴에 노출된다.

---

## 2. 메뉴·경로

| 항목 | 값 |
|------|-----|
| 메뉴명 | 특별 사용자 |
| URL | `/special` |
| i18n key | `menu.special` |
| 접근 | `SYSTEM_ADMIN`, `SPECIAL_USER` (`requiresMenu: true`) |
| 버튼 | 시드: `canRead`, `canUpdate` |

---

## 3. 기능 범위

| ID | 기능 | 설명 |
|----|------|------|
| S-01 | 권한 게이트 | 메뉴 Role 없으면 사이드바·라우트 접근 불가(403) |
| S-02 | 버튼 권한 UI | `v-can`으로 read/update/delete 등 표시 |

### 제외

- 실제 업무 CRUD·전용 API

---

## 4. API

전용 API 없음. 메뉴 권한만으로 화면 진입.

---

## 5. 수용 기준

- [ ] `USER` Role만 있는 계정은 메뉴·URL 접근 불가
- [ ] `SPECIAL_USER`는 화면 진입 가능
- [ ] 버튼 권한에 따라 UI 노출 차이
